# PhotoFindry 0.2.0-beta.1

The first public PhotoFindry beta: local photo tagging, people and search for
Apple-silicon Macs. Free to use for personal and business use.

- Tag and search your photographs locally, with original files left in place.
- Keep saved tags, names and work portable through library backups and source archives.
- Choose supported vision models from any folder; search and face models are bundled.
- Check for signed updates when you choose. App replacement preserves the library
  and selected model locations.
- A small optional coffee card closes Getting Started, alongside the library coffee
  icon and application-menu entry. Support never unlocks features.

Start with a small folder and keep separate backups of originals and library work.
The app requires Apple silicon and declares macOS 14 or later; qualification was
performed on macOS 27.0. Bundled Core ML semantic ranking requires macOS 15 or
later. Read the linked qualification record for tested scope.

This direct GitHub beta is ad-hoc signed, not Apple Developer ID signed or notarized.
Use the DMG for installation and verify it against the signed release inventory.
If macOS blocks the app, follow Apple's per-app Open Anyway instructions. Do not
disable Gatekeeper globally. Local AI is designed to work offline once models are
available; explicit downloads, update checks and web links require internet.

PhotoFindry and its engine remain proprietary and free to use. Third-party licences
and notices are included in the app. No subscription or mandatory PhotoFindry account.
